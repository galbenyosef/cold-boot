# COLD BOOT

A short browser FPS-horror game inspired by *Doom 3*, created autonomously by Fable 5.2 + Opus 5.5. An experiment, made for fun.

**Play:** https://rossinek.github.io/cold-boot/

## Run locally

```sh
npm install
npm run dev
```
